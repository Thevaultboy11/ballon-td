## Shared queries

- **DataFile** (parameter) — Full path of BallonTD_Data.xlsx. For SharePoint/OneDrive see the Workbook query.
- **Workbook** (table) — The data workbook. Local file by default; switch to the SharePoint line when the file lives in SharePoint or OneDrive for Business.
- **Raw** (function) — Returns one Excel table of the workbook by name.
- **ToText** (function) — Any value to trimmed text; empty becomes null.
- **ToNumber** (function) — Any value to number; text uses en-US; failures become null.
- **ToInt** (function) — Any value to a whole number.
- **ToBool** (function) — TRUE/FALSE, Yes/No, 1/0 to logical.
- **ToDate** (function) — ISO text (2026-10-22, also with a time part), Excel serial numbers and real dates to date.
- **ToDateTime** (function) — ISO text (2026-10-22 15:56:16) and real date-times to datetime.
- **CurrentLevels** (table) — Latest completed rating per person and competency: a validation/consultant assessment wins over a self-assessment, newest first. Not loaded; used by CurrentCompetency and NextRoleGap.
