# Input screens — manual build reference

Use this if pasting a `.yaml` file into Power Apps Studio is refused. Each screen is one container; build it by adding the controls below (names matter: the formulas refer to them) and pasting the formulas into the properties. Generated by `npm run powerbi:build`.

All screens need these data sources (Excel Online (Business) → BallonTD_Data.xlsx): `tbl_Employee`, `tbl_LookupValue`, `tbl_Staff`, `tbl_Competency`, `tbl_CompetencyBehavior`, `tbl_Course`, `tbl_CourseSession`, `tbl_Certification`, `tbl_ObservationParameter`, `tbl_TrainingRecord`, and the tables they write to (below).

## Coaching session — `01-Coaching.yaml`

Screen name `scrCoaching` · writes to `tbl_CoachingSession`

| Control | Type | Key properties |
| --- | --- | --- |
| `cbCoachingPerson` | Combo box | Items = SortByColumns(tbl_Employee, "name") · DisplayFields = ["name"] · DefaultSelectedItems = Filter(tbl_Employee, id = First(PowerBIIntegration.Data).'Employee ID') |
| `dpCoachingDate` | Date picker | DefaultDate = Today() · saved as text yyyy-mm-dd |
| `cbCoachingType` | Combo box | Items = Sort(Filter(tbl_LookupValue, list = "coachingType" && active), sortOrder) · DisplayFields = ["value"] · default "Monthly Check-In" |
| `cbCoachingCoach` | Combo box | Items = SortByColumns(Filter(tbl_Staff, "Coach" in roles), "name") · DisplayFields = ["name"] |
| `cbCoachingStatus` | Combo box | Items = Sort(Filter(tbl_LookupValue, list = "coachingStatus" && active), sortOrder) · DisplayFields = ["value"] · default "Completed" |
| `txtCoachingStartTime` | Text input | Default = "09:00" |
| `txtCoachingEndTime` | Text input | Default = "10:00" |
| `txtCoachingPrepMinutes` | Text input (number) | Format = TextFormat.Number · Default = "15" |
| `txtCoachingDurationMinutes` | Text input (number) | Format = TextFormat.Number · Default = "60" |
| `txtCoachingReportingMinutes` | Text input (number) | Format = TextFormat.Number · Default = "15" |
| `txtCoachingProgressPct` | Text input (number) | Format = TextFormat.Number |
| `txtCoachingSummary` | Text input (multi-line) | Default = "" |
| `txtCoachingChallenges` | Text input (multi-line) | Default = "" |
| `txtCoachingActionItems` | Text input (multi-line) | Default = "" |
| `dpCoachingNextReviewDate` | Date picker | DefaultDate = Blank() · saved as text yyyy-mm-dd |
| `tglCoachingEvidenceSubmitted` | Toggle | Default = false |
| `cbCoachingSource` | Combo box | Items = Sort(Filter(tbl_LookupValue, list = "source" && active), sortOrder) · DisplayFields = ["value"] · default "Direct entry" |
| `btnCoachingSave` | Button | OnSelect: see the Patch formula below |

Save button `OnSelect`:

```
Patch(tbl_CoachingSession, Defaults(tbl_CoachingSession), {
    id: "COA-PA" & Text(Now(), "yymmddhhmmss"),
    employeeId: cbCoachingPerson.Selected.id,
    date: If(IsBlank(dpCoachingDate.SelectedDate), Blank(), Text(dpCoachingDate.SelectedDate, "yyyy-mm-dd")),
    type: cbCoachingType.Selected.value,
    coachId: cbCoachingCoach.Selected.id,
    status: cbCoachingStatus.Selected.value,
    startTime: If(IsBlank(txtCoachingStartTime.Text), Blank(), txtCoachingStartTime.Text),
    endTime: If(IsBlank(txtCoachingEndTime.Text), Blank(), txtCoachingEndTime.Text),
    prepMinutes: If(IsBlank(txtCoachingPrepMinutes.Text), Blank(), Value(txtCoachingPrepMinutes.Text)),
    durationMinutes: If(IsBlank(txtCoachingDurationMinutes.Text), Blank(), Value(txtCoachingDurationMinutes.Text)),
    reportingMinutes: If(IsBlank(txtCoachingReportingMinutes.Text), Blank(), Value(txtCoachingReportingMinutes.Text)),
    progressPct: If(IsBlank(txtCoachingProgressPct.Text), Blank(), Value(txtCoachingProgressPct.Text)),
    summary: If(IsBlank(txtCoachingSummary.Text), Blank(), txtCoachingSummary.Text),
    challenges: If(IsBlank(txtCoachingChallenges.Text), Blank(), txtCoachingChallenges.Text),
    actionItems: If(IsBlank(txtCoachingActionItems.Text), Blank(), txtCoachingActionItems.Text),
    nextReviewDate: If(IsBlank(dpCoachingNextReviewDate.SelectedDate), Blank(), Text(dpCoachingNextReviewDate.SelectedDate, "yyyy-mm-dd")),
    evidenceSubmitted: tglCoachingEvidenceSubmitted.Value,
    source: cbCoachingSource.Selected.value,
    createdAt: Text(Now(), "yyyy-mm-dd hh:mm:ss"),
    createdBy: User().FullName,
    updatedAt: Text(Now(), "yyyy-mm-dd hh:mm:ss"),
    updatedBy: User().FullName
});
Notify("Coaching session saved. It appears in the report after the next refresh.", NotificationType.Success);
Reset(dpCoachingDate); Reset(cbCoachingType); Reset(cbCoachingCoach); Reset(cbCoachingStatus); Reset(txtCoachingStartTime); Reset(txtCoachingEndTime); Reset(txtCoachingPrepMinutes); Reset(txtCoachingDurationMinutes); Reset(txtCoachingReportingMinutes); Reset(txtCoachingProgressPct); Reset(txtCoachingSummary); Reset(txtCoachingChallenges); Reset(txtCoachingActionItems); Reset(dpCoachingNextReviewDate); Reset(tglCoachingEvidenceSubmitted); Reset(cbCoachingSource)
```

## Observation scores — `07-Observation.yaml`

Screen name `scrObs` · writes to `tbl_ObservationDay + tbl_ObservationScore`

| Control | Type | Key properties |
| --- | --- | --- |
| `cbObsPerson / cbObsSession / ddObsDay / dpObsDate / cbObsAttendance` | Combo boxes, drop down, date picker | see 07-Observation.yaml |
| `galObs` | Blank vertical gallery | Items = SortByColumns(Filter(tbl_ObservationParameter, active), "sortOrder") · inside: two labels (ThisItem.name, ThisItem.category) and drop down ddObsScore with Items = ["", "1", "2", "3", "4", "5"] |
| `btnObsSave` | Button | OnSelect: see below |

Save button `OnSelect`:

```
With({tr: LookUp(tbl_TrainingRecord, employeeId = cbObsPerson.Selected.id && sessionId = cbObsSession.Selected.id), dayId: "OBS-PA" & Text(Now(), "yymmddhhmmss")},
    If(IsBlank(tr.id),
        Notify("This person is not on that session. Add a training record first.", NotificationType.Error),
        Patch(tbl_ObservationDay, Defaults(tbl_ObservationDay), {
            id: dayId, trainingRecordId: tr.id, dayNumber: ddObsDay.Selected.Value,
            date: Text(dpObsDate.SelectedDate, "yyyy-mm-dd"), attendance: cbObsAttendance.Selected.value,
            potentialNote: cbObsPotential.Selected.value, notes: txtObsNotes.Text, source: "Trainer sheet",
            createdAt: Text(Now(), "yyyy-mm-dd hh:mm:ss"), createdBy: User().FullName, updatedAt: Text(Now(), "yyyy-mm-dd hh:mm:ss"), updatedBy: User().FullName
        });
        ForAll(Filter(galObs.AllItems, !IsBlank(ThisRecord.ddObsScore.Selected.Value) && ThisRecord.ddObsScore.Selected.Value <> ""),
            Patch(tbl_ObservationScore, Defaults(tbl_ObservationScore), {
                id: dayId & "-" & ThisRecord.code, observationDayId: dayId, parameterId: ThisRecord.id, score: Value(ThisRecord.ddObsScore.Selected.Value)
            })
        );
        Notify("Day " & ddObsDay.Selected.Value & " saved for " & cbObsPerson.Selected.name, NotificationType.Success)
    )
)
```
